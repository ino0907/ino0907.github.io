# らくがきモンスターでAIバトル! 公開キット

スマホ・パソコンのブラウザで遊べるように公開するための一式です。
ホーム画面に追加すると、アプリのように起動できます(PWA)。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体 |
| `monsters/` | 敵モンスター100体のイラスト(`<id>.jpg`)。差し替え・追加はここ |
| `api/judge.js` | AI判定サーバー。画像をClaude APIに送り、能力値のJSONを返す |
| `api/fetch.js` | 「URL指定」用。指定されたURLの画像をサーバー経由で取得する(内部ネットワークへのアクセスは拒否) |
| `manifest.webmanifest` / `sw.js` / `*.png` | ホーム画面追加・オフライン起動用 |
| `vercel.json` / `package.json` | Vercel用の設定 |
| `server.js` / `start.bat` | パソコンでの動作確認用(ローカルサーバー) |

AI判定のAPIキーは **サーバー側にだけ** 置きます。`index.html` には入れません。

## Windows のパソコンで試す(ローカル実行)

1. **Node.js** をインストールする(https://nodejs.org の LTS 版。すでに入っていれば不要)。
2. zip を右クリック →「すべて展開」。
3. 展開したフォルダの **`start.bat` をダブルクリック**する。
   - 初回だけ、Anthropic の API キーを聞かれます。貼り付けて Enter(フォルダ内に `.env` として保存されます)。
   - ブラウザが開き、`http://localhost:3000` でゲームが始まります。
   - 終了するときは、黒い画面で Ctrl+C を押すか、画面を閉じます。
4. 「Windows によって PC が保護されました」と出たら「詳細情報 → 実行」を選ぶ。

PowerShell で起動する場合:

```
cd 展開したフォルダ
$env:ANTHROPIC_API_KEY="sk-ant-..."
node server.js
```

### 同じ Wi-Fi のスマホから試す
- 起動時に表示される `http://192.168.x.x:3000` を、スマホのブラウザで開きます。
- Windows ファイアウォールの確認が出たら、「プライベート ネットワーク」を許可してください。
- この方法(http)では、「ホーム画面に追加」のアプリ化とオフライン起動は使えません(https が必要)。遊ぶ・撮影・お絵かき・AI 判定は使えます。
- `index.html` をダブルクリックで直接開く(`file:///...`)と、AI 判定は動きません。必ず `start.bat` から開いてください。

## 公開手順(Vercel の例・無料枠で始められます)

1. https://console.anthropic.com でAPIキーを作成する。あわせて **月の利用上限(Spend limit)** を設定しておく。
2. このフォルダをGitHubのリポジトリにする(またはVercel CLIで `vercel` を実行)。
3. https://vercel.com で「Add New → Project」から、そのリポジトリを選ぶ。
4. 「Environment Variables」に `ANTHROPIC_API_KEY` を追加して Deploy。
5. 発行されたURLをスマホで開き、遊べることを確認する。
   - iPhone: Safariの共有ボタン →「ホーム画面に追加」
   - Android: Chromeのメニュー →「ホーム画面に追加」(または「アプリをインストール」)

任意の環境変数: `MODEL`(使うモデル。初期値 `claude-sonnet-5-5`)、`RATE_PER_MIN`(1IPあたり1分の回数。初期値6)、`ALLOWED_ORIGIN`(自分のサイトのURLだけ許可)。

## 動作の仕組み

- 絵をアップロード・撮影・お絵かき → ブラウザ内で縮小(長辺512px) → `/api/judge` へ送信 → AIが名前・能力・特殊能力を判定。
- 判定に失敗したときは、ランダムな能力で遊べます(理由は画面に表示されます)。
- 記録したモンスター(最大20体)や図鑑の遭遇記録は、各自の端末のブラウザ内(localStorage)に保存されます。サーバーには保存しません。

## 運営時の注意

- **利用料**: 判定1回ごとにClaude APIの利用料がかかります。不特定多数に公開するなら、Anthropicコンソールの上限設定は必須です。
- **悪用対策**: `api/judge.js` には簡易のレート制限(インスタンス単位)だけが入っています。人気が出たら、VercelのFirewall/Rate Limitや、Upstash等を使った制限を追加してください。
- **プライバシー**: ユーザーのイラストは判定のためにサーバー経由でAnthropicのAPIに送信されます。公開時は、その旨をサイト上に明記してください。
- **画像素材**: 敵モンスターのイラストはこのプロジェクトのものです。利用条件(権利)は、公開前にご自身で確認してください。
- 別のホスティング(Cloudflare Pages / Netlify など)でも、`api/judge.js` と同じ処理をサーバー関数として置けば動きます。

## 画像の入れ方
アップロード / 📷撮影(スマホ) / ✏ その場で描く(ペン・消しゴム・塗りつぶし) / 🔗 URL指定 / 📚 記録から選ぶ。
URL指定は、このキットのサーバー(`api/fetch.js`)でのみ動きます。claude.ai上の試作版では使えません。
公開するときは、他人の画像を無断で使わないよう注意書きを入れてください。

## 記録とロック
アップロード・描画したモンスターは最大20体まで自動で記録されます。いっぱいになると、ロックされていない一番古いものから自動削除されます(図鑑で🔒を付けると残せます)。

## 背景とBGMを差し替える
- ステージ背景: `bg/` フォルダに、`bg/README.md` のファイル名で画像を置くだけで反映されます。
- BGM: `bgm/` フォルダに `title.mp3` / `battle.mp3` / `boss.mp3` を置くと反映されます。
- どちらも、置いていなければ、内蔵のグラデーションと自動演奏で動きます。

## 敵モンスターについて
- 敵は100体です(Lv1が18体、Lv2が20体、Lv3が22体、Lv4が22体、Lv5のボスが18体)。ソロでは、各レベルから1体ずつ抽選して5連戦します。
- イラストは `monsters/` フォルダの `<id>.jpg` です。差し替えるときは、同じ名前で上書きしてください。
- 能力値・ストーリー・お宝は `index.html` の中のデータ(`FOES` と `NEWMON`)にあります。
- 強さの調整: レベルごとの倍率は `LV_TUNE`、個別の倍率は `MON_TUNE` で変えられます。

## ★ モンスター合体
- ホーム画面の「★ モンスター合体」から、2体のモンスターを合体させて、新しいモンスターを作れます。
- 素材にできるのは、**自作モンスター(無条件)** と、**ソロで倒したことのある敵** です。
- 能力値は両方から引き継ぎ(平均とやや強い方に寄せて+10%)、特殊能力は両方から最大4つ、イラストは2体を重ねて合成します。
- 結果は自作モンスター(★付き)として記録されます。素材は消えません。記録がいっぱいのときは、ロックされていない古いものから自動削除されます。
